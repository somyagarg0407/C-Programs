# 📘 C Programming & Data Structures

This repository documents my learning journey in **C Programming** and the **Data Structures** concepts taught during my first year of college at **NIT Delhi**.

The purpose of this repository is to practice fundamental programming concepts, implement core data structures from scratch, and build a strong foundation before moving to advanced problem solving and backend development.

* Variables & Data Types
* Operators
* Conditional Statements
* Loops
* Functions

* Number System Conversion
* Basic Programming Problems

### 🔹 Data Structures

* Stack
* Queue
* Linked List
* Doubly Linked List
* Circular Linked List
* Trees

For each data structure, I implemented several common operations such as:

* Insertion
* Deletion
* Traversal
* Searching
* User-defined Position Operations (where applicable)

These implementations helped me understand how data structures work internally instead of only using built-in libraries.
